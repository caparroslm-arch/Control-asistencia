# Control de asistencia v4

Versión local del prototipo con los cambios solicitados.

## Novedades de v4
- Cuadro informativo en la asistencia de la sesión con alumnos registrados, asistentes, ausentes y pendientes.
- Balance mensual con indicadores destacados.
- Bloque destacado de alumnos que no han tenido ninguna asistencia durante el mes seleccionado.
- Resumen de asistentes y ausentes de cada sesión dentro del balance mensual.
- Se mantiene el registro de alumnos con nombre, correo y credenciales ocultas hasta pulsar el botón correspondiente.

## Demo
- Profesor: `profesor` / `profesor123`
- Alumnos: `ana.garcia` / `Ana2026`, `pablo.m` / `Pablo123`, `laura.s` / `Laura2026`

## Nota
Esta versión sigue funcionando como prototipo local con LocalStorage. El correo real, base de datos compartida y escaneo QR mediante cámara quedan para una fase posterior.
